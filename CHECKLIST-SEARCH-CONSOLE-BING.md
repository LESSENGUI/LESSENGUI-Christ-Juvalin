# Checklist exact de soumission et validation

## 1) Vérification du site en production
- Vérifier que le site Vercel est bien accessible.
- Tester les URLs suivantes :
  - https://lessengui-christ-juvalin.vercel.app/
  - https://lessengui-christ-juvalin.vercel.app/robots.txt
  - https://lessengui-christ-juvalin.vercel.app/sitemap.xml
  - https://lessengui-christ-juvalin.vercel.app/llms.txt
- Vérifier que chaque page retourne bien un statut HTTP 200.
- Vérifier qu’il n’y a pas d’erreurs JavaScript bloquantes sur les pages clés.

## 2) Google Search Console
1. Ouvrir Google Search Console.
2. Ajouter la propriété du site.
3. Choisir la méthode de vérification de propriété acceptée.
4. Ajouter la propriété Vercel :
   https://lessengui-christ-juvalin.vercel.app
5. Soumettre le sitemap :
   https://lessengui-christ-juvalin.vercel.app/sitemap.xml
6. Vérifier dans l’onglet :
   - Couverture
   - Erreurs d’exploration
   - Pages indexées
   - Requêtes et impressions
   - Amélioration du rendu mobile
   - Core Web Vitals
7. Contrôler les pages de marque et les pages long-tail.

## 3) Bing Webmaster Tools
1. Ouvrir Bing Webmaster Tools.
2. Ajouter la propriété du site.
3. Vérifier la propriété du domaine.
4. Soumettre le sitemap.
5. Vérifier :
   - indexation
   - couverture
   - requêtes de recherche
   - clics et impressions
   - erreurs de crawl

## 4) Validation SEO technique
- Vérifier les balises title et meta description sur la page d’accueil et sur les pages clés.
- Vérifier les href lang / canonical / og tags.
- Vérifier le JSON-LD grâce au validateur Schema.
- Vérifier la présence de mots-clés utiles dans les titres, descriptions et contenus de page.
- Vérifier les liens internes et la cohérence des uris de navigation.

## 5) Validation des pages IA / GEO / AEO
- Vérifier que /llms.txt est bien servi.
- Vérifier la qualité des descriptions de pages, notamment sur les pages clés.
- Vérifier les variantes de nom :
  - LESSENGUI Christ Juvalin
  - Christ Juvalin LESSENGUI
  - Christ LESSENGUI
  - Christ Juvalin Congo
- Vérifier que les pages de marque sont cohérentes entre elles.

## 6) Checklist hebdomadaire
- Contrôler les nouvelles pages indexées.
- Vérifier les erreurs d’exploration.
- Suivre les impressions et clics sur la marque.
- Mesurer les Core Web Vitals sur les pages clés.
- Revoir le contenu et les pages autour des requêtes de longue traîne.

## 7) Points de vigilance
- Ne pas publier de fausses informations, affiliations ou certifications non vérifiées.
- Ne pas acheter de liens ni créer des profils factices.
- Ne pas faire de mention de marges ou de réalisations non vérifiables.
- Garder une identité publique cohérente sur tous les canaux.

## 8) Finalité
L’indexation n’est pas garantie simplement par le code. Le succès passe par une combinaison de :
- contenu utile,
- structure claire,
- liens internes bien organisés,
- présence publique cohérente,
- confiance et notoriété réelle dans le temps.
